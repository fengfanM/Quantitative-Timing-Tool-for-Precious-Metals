# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-05-21

### Added

- Streamlit single-file domestic precious metals timing app.
- AKShare data pipeline for SGE gold/silver, macro factors, and realtime quotes.
- vectorbt backtesting with fees, slippage, and daily rebalancing.
- No-lookahead signal discipline: close-to-next-day execution via shifted weights.
- Strategy risk controls: single-position stop loss and 200-day moving-average defense.
- Realtime rebalance decision page with target weights and buy/sell amount suggestions.
- Robust parameter optimization with train/validation separation.
- Backtest integrity audit page section.
- Project documentation, license, contribution guide, security policy, and CI workflow.
